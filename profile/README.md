Ashraya (आश्रय — Sanskrit for the shelter that something else rests on) is a
macOS application that runs Windows games and other Windows programs on
Apple Silicon. It looks at a Windows binary, works out how to run it,
explains that decision in plain language, and then runs the program in an
isolated, versioned environment.

The project is in active, private development. Repositories aren't public
yet — this page is.
